Project Overview

This project demonstrates how data analytics can improve supply chain visibility and support business decisions. It combines PostgreSQL, Python, Apache Airflow, Docker and Apache Superset in an integrated analytics workflow.

Key Features

Data Management

PostgreSQL database for supply chain datasets and SQL analysis.

Python Analytics

Data cleaning, KPI development, supplier analysis and anomaly detection.

Demand Forecasting

30-day demand forecasting and inventory stockout-risk analysis.

Workflow Monitoring

Apache Airflow scheduling, execution monitoring and email alerts.

Interactive Dashboard

Apache Superset visualizations for operational monitoring.

Containerization

Docker Compose for running the supporting services.

Technology Stack

Python | Pandas | PostgreSQL | SQL | Apache Airflow | Apache Superset | Docker | Prophet

Project Results

  • Analyzed supplier, product, inventory, shipment and demand data.
  • Identified unusual supplier lead-time and demand patterns.
  • Generated 30-day demand forecasts for selected products.
  • Created inventory stockout-risk classifications.
  • Configured and tested Airflow monitoring and Gmail alerts.
  • Developed a Superset dashboard for supply chain KPIs.
